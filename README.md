# Inventory Management System

A full-stack Inventory Management System to manage products, stock, sales, and inventory operations efficiently.

## Features

- Product management
- Add, update, delete products
- Stock tracking
- Inventory monitoring
- Search products
- User authentication

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Python
- Flask 

Database:
- MySQL
